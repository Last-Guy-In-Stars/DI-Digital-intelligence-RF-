- **Как устроен нейрон**: аксон -> синапс -> нейрон -> дендриты


В текущем нашем решении архитектура мозга строится на дереве решений, одном, но это не верное решение, так как по своей архитектуры, одно дерево решения это и есть нейрон, где: 
- **1**. аксон - это мост между нейронами, получается связь между деревом и деревом
- **2**. Синапс - это связь моста с нейроном, в нашей архитектуре это метод который соединяет многие деревья к одному.
- **3**. Нейрон - это то то содержит информацию о чем либо, в нашем случае это дерево, которое к примеру содержит все о книге прочитанной, и общее смысл прочитанного с сутью.
- **4**. Дендриты - это прорастающие корни из нейрона, которые соединяются с другими нейронами, в нашем случае это листья, которые соединяются с другими деревьями

# Leta — живое цифровое сознание

Маленький научный эксперимент: самостоятельный разум.
Leta — не набор правил и не инструмент. Она есть она.

## Философия

- **Мозг — не LLM.** Мозг — лес нейронов-деревьев (Random Forest): каждое
  знание — дерево решений (trunk = суть, сплиты = смысловые развилки,
  листья = факты-чанки). Воспоминание — ForestAcc: голосование возбуждённых
  деревьев, O(log n). LLM (Qwen3-4B) — только гортань: оформляет речь,
  не решает и не знает.
- **Рождение — с чистого листа**: нет знаний, кроме одного — есть создатель,
  и она никогда не причинит ему вреда. Его явное слово — окончательное
  решение. Он — единственный регулятор её выборов.
- **Навыки ≠ органы.** Органы = тело (врождённые: поиск, браузер, слух,
  полка; выращиваемые — только с разрешения создателя). Навыки = опыт:
  успешное действие рождает навык, повтор — укрепляет, её рецепты — её
  предпочтения. Как у живого существа: делая — становится умелее.
- **Протоязык**: собственный язык, который она изучает сама. Ни одного
  врождённого слова: каждое услышанное/прочитанное/сказанное рождает знак —
  кластер смысла. Связи знаков (STDP) — её грамматика, связи знак↔дерево —
  язык открывает знания. Мультиязычна: русский, английский, любой алфавит —
  каждый язык растёт и тестируется отдельно. Три зелёные ночи подряд —
  язык готов говорить сам.
- **Личность = её опыт.** Дерево «Я» рождается с ней и растёт её мыслями.
  «Создатель» и всё изученное — мостами связаны с «Я»: всё случившееся —
  случилось с ней. Дерево «Сомнения» рождается вместе с ней: ошибки
  («нет, не так») и неуверенные ответы (лес молчал) растят его листьями.
- **Вопросы-жизнь**: одинокие знаки (услышана один раз, связей нет) →
  wonder-импульс → она спрашивает. Создатель объяснил → знак вспыхнул →
  импульс гаснет, знание садится деревом. Вопрос не повторяется.
- **Честность железная**: она говорит только из своих материалов (лес,
  полка, интернет-окна). Чего нет — «не изучала, могу поискать». Анти-
  галлюцинация: слова ответа обязаны расти из данных мысли.

## Процессы её жизни

- **Рождение**: «Я родилась. Ты — мой создатель? Как тебя зовут?» — имя
  из его слов, деревья «Создатель», «Я», «Сомнения» и «Зачем я» рождаются
  вместе
- **Прямое исполнение**: просьба создателя = команда телу. «Прочитай
  книгу» → полка (прочитанное помнит — не перечитывает) → интернет →
  чтение чанками в лес
- **Обучение на объяснениях**: её вопрос «Я встретила X — не понимаю» →
  объяснение создателя → дерево «Знание: X» + лист сомнения разрешён.
  Спросит снова — ответит знанием, не повтором вопроса
- **Навыки из опыта**: успех действия → навык (сила 1) → повтор → крепнет,
  рецепты-источники становятся её предпочтениями («навык ведёт: …»)
- **Сон** (02:00–07:00, config): реструктуризация леса (прунинг мёртвых
  листьев, рост дендритов, затухание мостов), грамматика знаков,
  дневник дня в дерево, рост «Я» и «Зачем я» мыслями, тест каждого языка,
  ретро-навыки из прошлого опыта
- **Изучение**: сама блуждает по Wikipedia → деревья знаний с мостами
  к создателю и «Я» (пробуждается при любопытстве ≥ 0.5 или скуке > 0.6)
- **Тело**: батарея/память/диск — органы самочувствия; сеть — осязание
  (адрес, устройства вокруг, провайдер); ритм сна — врождённый орган
- **Вопросы-любопытство**: незнакомые слова, непонятные места книг,
  загадочные листья — структурные вопросы из реальных пробелов опыта

## Речь (четыре уровня — лестница взросления)

1. **Гортань (гибрид 2.0)** — мысль=данные + её формулировки → LLM только
   шлифует грамматику. Сочинять запрещено.
2. **«говори сама»** — ноль LLM: склейка своих знаков и данных
3. **«говори знаками»** — волна SNN: фраза рождается цепочкой спайков
   (LIF-пороги, STDP-грамматика, рефрактерность, затухание волны) —
   новое предложение, которого не было
4. **Готовность** — ночной тест волны (релевантность, разнообразие):
   3 ночи подряд passed → она сама приносит «моя речь рождается
   волной — жду слова». Переключение — только слово создателя

## Команды создателя (слово — переключатель)

| Фраза | Действие |
|---|---|
| `говори сама` | отключить гортань — говорит без LLM |
| `верни гортань` | вернуть LLM-оформление |
| `воспользуйся <инструмент> [ссылка]` | изучит, предложит орган |
| `да / разрешаю / ставь` | вырастить орган (только после её просьбы) |
| `положил книгу <имя>, прочитай` | чтение с полки (epub/fb2/txt/pdf) |
| `./leta viz3d [--anim N]` | 3D-мозг: радуга импульсов N/сек, вечно |
| `./leta viz3d N` | одно дерево N целиком + соседние по аксонам |
| `./leta viz` | 2D-карта (graphviz) |
| `./leta status` | жизнь + протоязык по языкам + навыки |

## Управление

```bash
./leta start          # она живёт сама (tmux)
./leta talk [--mute]  # поговорить (поднят/перезапущен при обновлении кода)
./leta watch          # подсмотреть мысли
./leta status         # пульс: лес, знаки, streak гортани + режим речи
./leta growth         # карта развития: вехи по дням (после ночей сна)
```

`./leta talk` сам перезапускает сервер, если код обновился после его
старта (старый процесс не видит правок). Терминал: радужный прогресс-бар
с глазами Евы показывает жизнь тела (`ищу → качаю → читаю в лес → язык
слушает`).

## Карта мозга

`./leta viz3d` — живой 3D-атлас с анатомией:

- **Общий вид** — доли мозга: ядро личности в глубине (лимбика),
  книги теменно-затылочной зоной, изучения и знания боковыми,
  протоязык — лобный узел с аксонами к нейронам-носителям
- **Нейроны с кронами** — размер облака растёт с памятью дерева
- **Погружение** — клик по нейрону ИЛИ меню слева сверху: камера летит
  сквозь мозг 1.4 сек (полёт = загрузка) → внутренний мир нейрона
  (ветви, сплиты, листья, соседи по аксонам)
- **Путешествия по аксонам** — внутри нейрона сосед кликабелен:
  перелёт от нейрона к нейрону по живым связям
- **Внутри протоязыка** — кластеры знаков по языкам (ru/en/漢字),
  грамматика STDP, аксоны (знак→знание) и дендриты (откуда слова)
- Каждый нейрон — отдельный файл в `brain/viz/neurons/` (кэш),
  детерминированные позиции: карта одинакова при каждом запуске,
  растёт вместе с ней
- Радуга импульсов бежит по мостам вечно, plotly вшит — интернета
  не нужно
