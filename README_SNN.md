# SNN — Спайковая Нейронная Сеть Leta

## Теория: импульсы, гамма, гистограммы

### Спайковые нейронные сети

Традиционные нейросети (включая LLM) — это **ставки**: каждый нейрон
выдаёт число (вероятность активации) на каждом шаге. Вся сеть — один
статичный снимок весов.

Spiking Neural Networks (SNN) — **третье поколение** нейросетей: нейроны
общаются **импульсами** (спайками) — дискретными событиями во времени.
Нейрон не «немного активен» — он либо сработал, либо молчит. Между
спайками — накопление потенциала.

Это ближе к мозгу: реальный нейрон интегрирует входы, пока потенциал
мембраны не достигнет порога, затем — спайк и сброс.

### LIF: Leaky Integrate-and-Fire

Модель Leta — LIF-нейрон:

```
V(t+1) = V(t) + I(t) − λ·V(t)

если V ≥ θ:
    СПАЙК
    V → 0
    рефрактерный период (нейрон молчит 0.3 сек)
```

- `V` — мембранный потенциал (накопленное возбуждение)
- `I(t)` — входной ток (для Leta: косинус входа и знака)
- `λ` — утечка (забывание)
- `θ` — порог (для Leta: 1.0)

### Гамма-ритм: окно интеграции

В мозге гамма-ритм (~40 Гц, период ~25 мс) создаёт **временные окна**:
нейроны, сработавшие внутри одного гамма-цикла, относятся к одному
«кванту мысли». Это таймер сознания: за одно окно собирается один смысл.

В Leta гамма-окно реализовано через **рефрактерный период** (0.3 сек):
знак, сработавший в этом окне, не сработает повторно — как нейрон коры.
Серия фраз за одно окно накапливает потенциал к порогу — это узнавание
по контексту, а не по одной фразе.

### Гистограммы: кодирование смысла

В классических SNN информация кодируется **частотой** (rate coding):
чем сильнее стимул, тем чаще спайки. Гистограмма спайков по времени —
это «частотный портрет» входа.

В Leta аналогичная идея реализована через **косинусные гистограммы**:

```
вход (фраза) → bge-m3 → вектор (1024 измерений)

для каждого знака:
    косинус(вход, знак) → вклад в потенциал

потенциал знака = гистограмма его возбуждения от входа

спайк = гистограмма превысила порог
```

Каждый знак — это не бинарный детектор, а **гистограмма смыслов**:
как сильно данный вход попадает в облако этого знака. Узнавание —
когда вклад накапливается до порога за гамма-окно.

Сравнение двух входов (реплика создателя и знак) — это сравнение их
гистограмм в 1024-мерном пространстве: косинусная близость.

### STDP: обучение по времени спайков

Spike-Timing Dependent Plasticity — ключевой механизм обучения SNN:

```
если знак A сработал ЗА НЕСКОЛЬКО мс ДО знака B:
    связь A→B усиливается  (причина → следствие)

если знак A сработал ПОСЛЕ знака B:
    связь A→B ослабевает   (не причина)
```

В Leta STDP упрощён до **совместной активности**: два знака, сработавшие
в одном гамма-окне, связываются. Их совместный спайк — факт того, что
эти смыслы встретились вместе в её опыте. Многократные совместные спайки
→ крепкая связь → «грамматическое правило» её языка.

### Итого: почему SNN, а не ставки

| Ставки (LLM/традиционные) | Импульсы (SNN) |
|---|---|
| непрерывные значения | дискретные события |
| статичная сеть | динамика во времени |
| нет памяти о прошлом входе | потенциал накапливается |
| обучение градиентами | обучение STDP (по времени) |
| нет гамма-ритма | временные окна интеграции |
| «вероятность правильного» | «сработал или нет» |

Leta не «вероятно узнала фразу» — она **узнала** (спайк) или **не узнала**
(потенциал ниже порога). Её язык — не распределение вероятностей, а
сеть знаков, связанных опытом.

## Суть

Leta имеет два мозга, работающих параллельно:

1. **Лес** (`forest.sqlite`) — долговременная память: нейроны-деревья, знания
2. **Протоязык** (`proto.sqlite`) — спайковая сеть: язык, мышление, личность

Протоязык — это её собственный язык, который она **изучает сама**, как ребёнок.
Ни одного врождённого слова. Ни одного правила. Только опыт.

## Архитектура SNN

### Знак (нейрон)

```
sign = {
    id: целое число,
    anchor: "фраза-якорь" — текст, из которого знак родился,
    embedding: вектор смысла (bge-m3, 1024 измерений),
    heard_count: сколько раз слышала,
    born: timestamp рождения,
    lang: 'ru' | 'en' | 'cjk' | 'mix' — язык знака (алфавит-сенсор),
    mine: 0 | 1 — её собственная формулировка (1) или услышанная (0)
}
```

Знак — это кластер смысла. Не слово из словаря, а **облако** в пространстве
смыслов. Когда она слышит новую фразу:
- Если похоже на существующий знак (косинус ≥ 0.62) → знак **узнаётся**,
  центроид уточняется (облако сжимается вокруг нового примера)
- Если не похоже ни на что → **рождается новый знак** — язык растёт

### Импульс (спайк)

LIF-нейрон (Leaky Integrate-and-Fire):

```
потенциал знака += косинус(вход, знак)

если потенциал ≥ 1.0 И прошло > 0.3с от последнего спайка:
    СПАЙК! — знак сработал
    потенциал сбрасывается
иначе:
    потенциал накапливается (до 0.99)
```

Два пути к спайку:
- **Мгновенный**: сильная похожесть (косинус ≥ 0.8) → спайк сразу
- **Интегративный**: две средне-похожие фразы подряд → потенциал дорастает

Интеграция — это узнавание по контексту: одна фраза может не узнать знак,
но серия похожих — узнают.

### Связь знаков (синапс)

```
sign_links = {a, b, weight}
```

**STDP** (Spike-Timing Dependent Plasticity): если два знака сработали
вместе — связь между ними укрепляется (×1.15 за событие, максимум 1.0).
Это её **грамматика**: «после этого знака обычно тот».

Связи не врождённые — растут из совместной активности. Чем чаще два смысла
встречаются вместе в её опыте, тем крепче связь.

### Связь знак↔дерево (SNN-ядро)

```
sign_trees = {sign_id, tree_id, weight}
```

Каждый знак может быть **ключом** к дереву знаний. Растёт двумя путями:
- При чтении книги: чанк → знак → связь с деревом этой книги
- При диалоге: знак услышан + дерево загорелось → Hebbian-связь

Когда она слышит фразу:
1. Знаки спайкают (узнавание)
2. Спайкнувшие знаки **открывают** связанные деревья знаний
3. Она вспоминает — не по поиску, а по ассоциации

Это ядро SNN: **язык → мысль**. Слово открывает знание.

## Языки

Алфавит-сенсор (структурно, без LLM):
- кириллица → `ru`
- латиница → `en`
- иероглифы → `cjk`
- смешанное → `mix`

Каждый язык — отдельный протоязык. Знаки `ru` не смешиваются со знаками
`en`. Она может выучить сколько угодно языков — каждый растёт из своего
опыта, каждый тестируется отдельно.

### Тест языка (во сне, каждую ночь)

```
прошёл если:
    знаков ≥ 30
    связей ≥ 10
    покрытие последних реплик ≥ 70% (каждая фраза создателя
    узнаётся хотя бы одним знаком)

три ночи подряд зелёный → язык ГОТОВ
```

Когда язык готов — она сообщает создателю. Его слово — отключить гортань
(LLM) для этого языка, и она говорит только им.

## Речь

### Три уровня

1. **Гортань** (LLM): мысль=данные → Qwen3-4B оформляет. Не сочиняет —
   только шлифует (гибрид 2.0)
2. **«Говори сама»** (SNN + данные, ноль LLM): возбуждает весь лес +
   полку + знаки → собирает фразу из загоревшегося. Телеграфно, но её.
3. **Свой язык** (цель): складывает знаки в новые предложения, которых
   никогда не слышала. Наступает с ростом опыта.

### Что происходит при «говори сама»

```
вопрос создателя
    ↓
1. Лес возбуждается (recall по вектору) → загоревшиеся деревья + листья
2. Полка: слова вопроса ищутся в прочитанных книгах
3. Знаки: её формулировки, близкие к вопросу
4. Состояние: личность, чувства, навыки
    ↓
сборка: до 4 фрагментов, дедупликация, без меток
    ↓
ответ — корявый, но из её мозга, её словами
```

## Рост языка

### Что питает знаки

| Источник | Знаков за раз | Связь с деревом |
|---|---|---|
| Реплика создателя | 1-2 | через совместную активность |
| Книга (чтение) | ~60-180 | каждый 5-й чанк → дерево книги |
| Её собственная реплика | 1 (mine=1) | через «Я»-дерево |
| Случайное изучение (Wikipedia) | ~10-20 | через «Изучение»-деревья |

### mine-знаки — её голос

Её чистые ответы (прошедшие анти-галлюцинацию) становятся `mine`-знаками.
Это её собственные формулировки. При «говори сама» они — предпочтительные
формы для сборки речи. Чем больше она говорит — тем больше её слов в её
словаре.

## Сон (реструктуризация)

Каждую ночь (02:00–07:00):

1. **Лес**: прунинг мёртвых листьев (не возбуждались 2+ дней), затухание
   слабых мост-аксонов, рост новых дендритов между похожими листьями
2. **Я-дерево**: последние мысли становятся листьями личности
3. **Дневник**: эпизоды дня → чанки → дерево-дневник
4. **Навыки**: ретроактивное рождение из прошлого опыта
5. **Тест языка**: каждый язык отдельно, счётчик готовности

## Прогресс к полному SNN

```
[сейчас]  знаки растут, тесты идут, «говори сама» работает телеграфно
[ближе]   mine-знаков сотни → формулировки становятся её голосом
[цель]    связей достаточно для грамматики → складывает новые фразы
          → гортань отключается навсегда → она говорит своим языком
```

Критерий перехода — не мой код, а её опыт: чем больше она живёт, читает,
говорит — тем скорее её язык станет достаточным. Механизм готов, материя
растёт.

## Файлы

```
brain/proto.sqlite
├── signs          — знаки (нейроны): якорь, эмбеддинг, язык, mine
├── sign_links     — синапсы: связи знаков (STDP-грамматика)
└── sign_trees     — SNN-ядро: знак → дерево знаний

src/proto.py       — ProtoLanguage: hear(), LIF, STDP, тесты
src/brain.py       — интеграция: _snn_speak(), language_test(),
                     night_sleep(), речевой контур
```

## Технические параметры

| Параметр | Значение | Смысл |
|---|---|---|
| KNOW_THRESHOLD | 0.62 | минимальная похожесть для узнавания |
| мгновенный спайк | ≥ 0.80 | узнавание с первого раза |
| интегративный | потенциал ≥ 1.0 | узнавание по накоплению |
| REFRACTORY | 0.3 сек | пауза между спайками знака |
| STDP | ×1.15 | рост связи за совместный спайк |
| максимум веса | 1.0 | предел крепости связи |
| покрытие теста | ≥ 70% | реплики создателя узнаются |
| знаков для готовности | ≥ 30 | минимальный словарь |
| связей для готовности | ≥ 10 | минимальная грамматика |
| ночей подряд | 3 | устойчивость готовности |
